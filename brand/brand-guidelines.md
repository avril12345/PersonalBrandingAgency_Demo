# LOUD Brand Guidelines

LOUD is a personal branding agency for C-suite and director-level executives.

## Color palette

| Token | Hex | Use |
|---|---|---|
| `--loud-red` | `#E10600` | Primary brand color: logo, primary buttons, key highlights |
| `--loud-red-dark` | `#A30400` | Hover/pressed states, headings on light backgrounds |
| `--loud-crimson` | `#6B0F1A` | Deep accents, dark-mode surfaces |
| `--loud-blush` | `#FDECEC` | Tinted backgrounds, cards, table stripes |
| `--loud-ink` | `#141414` | Body text, dark backgrounds |
| `--loud-paper` | `#FFFFFF` | Page background |
| `--loud-gray` | `#6E6E6E` | Secondary text, captions |

```css
:root {
  --loud-red: #E10600;
  --loud-red-dark: #A30400;
  --loud-crimson: #6B0F1A;
  --loud-blush: #FDECEC;
  --loud-ink: #141414;
  --loud-paper: #FFFFFF;
  --loud-gray: #6E6E6E;
}
```

## Usage rules
- Red is the signal color. Use it for the one thing on a page that matters most, not for everything.
- Body text is always ink on paper (or paper on ink). Never set long text in red.
- The wordmark is always uppercase: **LOUD**.
